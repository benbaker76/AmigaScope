# Custom chips: interrupt enable and request

Paula collects every interrupt source into INTREQ, masks it with INTENA and drives the
680x0 interrupt priority lines (levels 1-6). Level 7 (NMI) is not generated by the
Amiga. CIA-A is wired to level 2 (PORTS), CIA-B and the INT6 expansion line to level 6
(EXTER).

Bit map shared by all four registers:

| Bit | HRM name | NDK flag (intbits.i) | CPU level | Source |
|---|---|---|---|---|
| 15 | SET/CLR | `INTF_SETCLR` | -- | write only: 1 = set, 0 = clear the bits written as 1 |
| 14 | INTEN | `INTF_INTEN` | -- | master enable (INTENA only, never a request) |
| 13 | EXTER | `INTF_EXTER` | 6 | INT6 line: CIA-B, expansion |
| 12 | DSKSYN | `INTF_DSKSYNC` | 5 | disk data matched DSKSYNC |
| 11 | RBF | `INTF_RBF` | 5 | serial receive buffer full |
| 10 | AUD3 | `INTF_AUD3` | 4 | audio channel 3 block done |
| 9 | AUD2 | `INTF_AUD2` | 4 | audio channel 2 block done |
| 8 | AUD1 | `INTF_AUD1` | 4 | audio channel 1 block done |
| 7 | AUD0 | `INTF_AUD0` | 4 | audio channel 0 block done |
| 6 | BLIT | `INTF_BLIT` | 3 | blitter finished |
| 5 | VERTB | `INTF_VERTB` | 3 | start of vertical blank (line 0) |
| 4 | COPER | `INTF_COPER` | 3 | Copper (a Copper MOVE to INTREQ) |
| 3 | PORTS | `INTF_PORTS` | 2 | INT2 line: CIA-A (keyboard, timers), expansion |
| 2 | SOFT | `INTF_SOFTINT` | 1 | software interrupt |
| 1 | DSKBLK | `INTF_DSKBLK` | 1 | disk DMA block finished |
| 0 | TBE | `INTF_TBE` | 1 | serial transmit buffer empty |

`INTB_` names give the bit numbers. Autovectors (vector numbers 25-31, confirmed by the
NDK `exec/alerts.i` codes `ACPU_AutoVec1`-`7` = `$80000019`-`$1F`; offsets relative to
VBR on 68010+): level 1 `$64`, 2 `$68`, 3 `$6C`, 4 `$70`, 5 `$74`, 6 `$78`, 7 `$7C`.

## INTENA
`$DFF09A` · write (set/clear) · Paula · OCS · read back via INTENAR `$DFF01C`

Enable or disable individual interrupt sources and the master interrupt enable.

| Bit | Name | Level | Meaning |
|---|---|---|---|
| 15 | SET/CLR | -- | 1 = set the 1-bits written, 0 = clear them |
| 14 | INTEN | -- | master enable: 0 blocks every source |
| 13 | EXTER | 6 | CIA-B / INT6 |
| 12 | DSKSYN | 5 | disk sync match |
| 11 | RBF | 5 | serial receive |
| 10-7 | AUD3-AUD0 | 4 | audio block done |
| 6 | BLIT | 3 | blitter finished |
| 5 | VERTB | 3 | vertical blank |
| 4 | COPER | 3 | Copper |
| 3 | PORTS | 2 | CIA-A / INT2 |
| 2 | SOFT | 1 | software |
| 1 | DSKBLK | 1 | disk block |
| 0 | TBE | 1 | serial transmit |

NDK: `intena` (custom.i); `INTF_` / `INTB_` names above (intbits.i); C `custom->intena`.

### Example
```asm
        include "hardware/custom.i"
        include "hardware/intbits.i"
        lea     $dff000,a6
        move.w  intenar(a6),OldIntena           ; save
        move.w  #$7fff,intena(a6)               ; everything off
        move.w  #$7fff,intreq(a6)               ; drop pending requests
        move.l  $6c.w,OldLevel3                 ; bare metal, VBR = 0 assumed
        move.l  #Level3,$6c.w
        move.w  #INTF_SETCLR!INTF_INTEN!INTF_VERTB,intena(a6)
        ; ... on exit:
        move.w  #$7fff,intena(a6)
        move.l  OldLevel3,$6c.w
        move.w  OldIntena,d0
        or.w    #INTF_SETCLR,d0
        move.w  d0,intena(a6)
```

### Gotchas
- Same set/clear protocol as DMACON: `$7FFF` disables all, set and clear need two writes.
- A source only interrupts when both its bit and INTEN (bit 14) are set.
- On 68010+ the vector table can be moved by VBR: read VBR (in supervisor mode) instead of
  assuming `$6C.w`. OS-friendly code should use `AddIntServer` / `SetIntVector` (see the
  amiga-os skill) instead of poking vectors.
- Disable the source in INTENA before you remove its handler.

**See also:** INTENAR, INTREQ, [DMACON](dma-beam.md#dmacon), [ICR](cia.md#icr)

## INTENAR
`$DFF01C` · read · Paula · OCS · write via INTENA `$DFF09A`

Read which interrupt sources and the master enable are currently on.

Bits 14-0 as in INTENA (full map at the top of this file); bit 15 has no meaning.

NDK: `intenar` (custom.i); C `custom->intenar`.

### Gotchas
- A pending request only matters if it is also enabled: in a shared handler test
  `INTREQR & INTENAR`, not INTREQR alone.
- To restore a saved value, OR it with `INTF_SETCLR` after first writing `$7FFF`.

**See also:** INTENA, INTREQR

## INTREQ
`$DFF09C` · write (set/clear) · Paula · OCS · read back via INTREQR `$DFF01E`

Clear serviced interrupt requests, or set a request to trigger an interrupt from software.

| Bit | Name | Level | Meaning |
|---|---|---|---|
| 15 | SET/CLR | -- | 1 = raise the requests written as 1, 0 = clear (acknowledge) them |
| 14 | INTEN | -- | not a request, write 0 |
| 13 | EXTER | 6 | CIA-B / INT6 |
| 12 | DSKSYN | 5 | disk sync match |
| 11 | RBF | 5 | serial receive (also resets SERDATR OVRUN) |
| 10-7 | AUD3-AUD0 | 4 | audio block done |
| 6 | BLIT | 3 | blitter finished |
| 5 | VERTB | 3 | vertical blank |
| 4 | COPER | 3 | Copper |
| 3 | PORTS | 2 | CIA-A / INT2 |
| 2 | SOFT | 1 | software |
| 1 | DSKBLK | 1 | disk block |
| 0 | TBE | 1 | serial transmit |

NDK: `intreq` (custom.i); `INTF_` / `INTB_` names (intbits.i); C `custom->intreq`.

### Example
```asm
Level3: movem.l d0-d1/a0-a1/a6,-(sp)
        lea     $dff000,a6
        move.w  intreqr(a6),d0
        and.w   intenar(a6),d0                  ; only enabled sources
        and.w   #INTF_VERTB!INTF_COPER!INTF_BLIT,d0
        btst    #INTB_VERTB,d0
        beq.s   .novb
        ; ... per-frame work
.novb   move.w  d0,intreq(a6)                   ; bit 15 = 0: acknowledge what we saw
        move.w  d0,intreq(a6)                   ; second write: fast CPUs (unverified)
        movem.l (sp)+,d0-d1/a0-a1/a6
        rte

; Copper list: raise a Copper interrupt on line $80
        dc.w    $8001,$fffe
        dc.w    intreq,INTF_SETCLR!INTF_COPER
```

### Gotchas
- Requests are never cleared automatically: a handler that does not clear its bit is
  re-entered forever (the machine locks, only higher levels still run).
- Clear the cause first (e.g. read the CIA ICR for PORTS/EXTER), then clear INTREQ,
  normally just before `RTE`. Acknowledging a CIA interrupt before reading ICR leaves the
  CIA line asserted and the request comes straight back.
- On 68020+ running from fast RAM, write the clear twice before `RTE`; a single write can
  reach `RTE` before Paula drops the interrupt line and the handler runs again
  (unverified).
- Acknowledge only the bits you serviced: `$7FFF` also throws away requests from other
  sources on other levels.
- Level 3 is shared by VERTB, COPER and BLIT: test which one fired.
- Use `move.w`, never `clr.w` or `bset`/`bclr`, on this write-only register (those read it
  first).

**See also:** INTREQR, INTENA, [ICR](cia.md#icr), [COPINS](copper.md#copins)

## INTREQR
`$DFF01E` · read · Paula · OCS · write via INTREQ `$DFF09C`

Read which interrupt requests are pending, whether or not they are enabled.

Bits 14-0 as in INTREQ (full map at the top of this file); bit 15 has no meaning.

NDK: `intreqr` (custom.i); C `custom->intreqr`.

### Example
```asm
; poll for vertical blank without an interrupt handler
.wait   btst    #INTB_VERTB,intreqr+1(a6)       ; bit 5 lives in the low byte
        beq.s   .wait
        move.w  #INTF_VERTB,intreq(a6)          ; clear it for the next frame
```

### Gotchas
- Pending bits stay set until written to INTREQ, even for disabled sources: polling code
  must clear the bit after seeing it.
- Byte-sized `btst` on memory: use `intreqr+1` for bits 7-0 and `intreqr` with `n-8` for
  bits 15-8.
- SERDATR mirrors RBF and TBE, but clearing still goes through INTREQ.

**See also:** INTREQ, INTENAR, [SERDATR](input-serial.md#serdatr)
