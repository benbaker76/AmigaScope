# utility.library

utility.library (V36+, in the Kickstart ROM from 2.0) is the toolbox other libraries are built
on: tag list parsing and editing, the standard callback Hook, 32- and 64-bit integer math that
works on a 68000, Amiga date conversion, locale-aware case-insensitive string compares, V39
namespaces of named objects, and a system-wide unique ID counter. Intuition, BOOPSI, layers
hooks and every `...TagList` call rely on its structures.

## Opening

- Name `"utility.library"` (`UTILITYNAME` in utility/utility.h, a macro emitting the string in
  utility.i). Base variable **`UtilityBase`**: `struct UtilityBase *` in Bartman's
  `<proto/utility.h>` (a `struct Library` followed by `ub_Language`, `ub_Reserved`).
- It does not exist on Kickstart 1.3 (V34) or earlier. Open version **36** for tags, hooks, dates
  and 32-bit math, **37** for Stricmp/Strnicmp/ToUpper/ToLower, **39** for ApplyTagChanges,
  SMult64/UMult64, Pack/UnpackStructureTags, the named-object calls and GetUniqueID.
- C: `#include <proto/utility.h>` plus `<utility/tagitem.h>`, `<utility/hooks.h>`,
  `<utility/date.h>`, `<utility/name.h>`, `<utility/pack.h>` as needed. asm:
  `include "utility/tagitem.i"` (etc.) and `include "lvo/utility_lib.i"`.

```c
#include <proto/exec.h>
#include <proto/utility.h>
#include <utility/utility.h>

struct UtilityBase *UtilityBase;

UtilityBase = (struct UtilityBase *)OpenLibrary((CONST_STRPTR)UTILITYNAME, 39);
if (UtilityBase == NULL)
    return 20;                          /* needs OS 3.0 utility.library */
/* ... */
CloseLibrary((struct Library *)UtilityBase);
```

## Calling convention

- A6 = `UtilityBase`, `jsr _LVOname(a6)`; arguments in the registers on each entry's `Registers:`
  line, result in D0. D0, D1, A0, A1 are scratch; D2-D7/A2-A6 are preserved.
- **Exception, the math calls** (SMult32, UMult32, SDivMod32, UDivMod32, SMult64, UMult64): the
  autodocs say they do not need A6 = UtilityBase and they preserve ALL address registers
  (A0 and A1 included). The second result half comes back in D1 (see [math.md](math.md)).
- [CallHookPkt](hooks.md#callhookpkt) takes the object in **A2** and the message in **A1** -- the
  hook convention, not the C argument order.
- BOOL results (TagInArray, AddNamedObject) are 16-bit in C: test `tst.w d0`. ToUpper/ToLower
  return a UBYTE: use only the low byte.
- Stricmp, Strnicmp, ToUpper and ToLower are replaced by language-specific code when
  locale.library is running, so their results can change with the user's language setting.

| Version | Release | Added |
|---|---|---|
| V36 | 2.0 | tag functions (Find/Get/Next/PackBool/Filter/Map/Allocate/Clone/Free/Refresh/TagInArray), CallHookPkt, Amiga2Date/Date2Amiga/CheckDate, SMult32/UMult32/SDivMod32/UDivMod32 |

| V39 | 3.0 | ApplyTagChanges, SMult64/UMult64, PackStructureTags/UnpackStructureTags, named objects and namespaces, GetUniqueID; MapTags honours its mapType (always "keep" before) |

The NDK 3.9 SFD lists no utility.library functions newer than V39.
