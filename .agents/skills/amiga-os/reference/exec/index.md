# exec.library

The kernel: memory, lists, tasks, signals, messages, interrupts, libraries, devices and
semaphores. Every other library is opened through it.

## Base and opening

- Base variable: `SysBase` (C: `struct ExecBase *SysBase`; asm: `move.l 4.w,a6`).
- exec is never opened: its base is the longword at absolute address 4 (amiga.lib exports
  the same value as `_AbsExecBase`).
  Read it once at startup, from address 4 itself, and keep it in your own variable.
  Bartman's template does `SysBase = *((struct ExecBase **)4UL);`.
- Version check: `SysBase->LibNode.lib_Version` (asm `LIB_VERSION(a6)`, a UWORD at +$14).
  Stock ROMs: 1.2 = V33, 1.3 = V34, 2.0 = V36, 2.04 = V37, 3.0 = V39, 3.1 = V40.
- C: `#include <proto/exec.h>` (inline macros emit `jsr -LVO(a6)` with `a6 = SysBase`).
  The inline headers look for the global name `SysBase` itself, so don't rename it.
- asm: `include "exec/<x>.i"` for structures/flags and `include "lvo/exec_lib.i"` for the
  `_LVOxxx` offsets, then `jsr _LVOxxx(a6)`.

See [calling convention](../topics/calling-convention.md) and
[opening libraries](../topics/opening-libraries.md).

## Register convention

- A6 must hold `SysBase` at the `jsr`. Arguments go in the registers given on each entry's
  `Registers:` line. The result comes back in D0.
- D0, D1, A0 and A1 are scratch: assume every call trashes them. D2-D7 and A2-A6 are preserved.
- Don't trust the condition codes after a call. Test D0 yourself (`tst.l d0`). FindName is the
  only exec call documented to return with Z set to match D0.
- BYTE results (DoIO, WaitIO, OpenDevice, AllocSignal, SetTaskPri) are only guaranteed in the
  low byte. The autodocs say DoIO, WaitIO and OpenDevice sign-extend. For the others, test
  with `tst.b` or cast in C.
- Odd ones: Alert takes D7. Supervisor takes A5. SetFunction uses only the low word of A0.
  Forbid, Permit, Disable, Enable and GetCC preserve all registers. So do ReleaseSemaphore,
  and ObtainSemaphore and ObtainSemaphoreShared from V37 on.
- Interrupt code may call only the functions documented as safe there: Signal, ReplyMsg,
  Cause, Disable/Enable, and Alert when it is non-recoverable. Never AllocMem, Wait,
  OpenLibrary or anything that can block.

## Version landmarks

- **V33 (1.2)** -- signal semaphores (InitSemaphore ... RemSemaphore), AddMemList, CopyMem,
  CopyMemQuick, SumKickData.
- **V36 (2.0)** -- AllocVec/FreeVec, CreateMsgPort/DeleteMsgPort,
  CreateIORequest/DeleteIORequest, ObtainSemaphoreShared, ColdReboot, `MEMF_REVERSE`.
  Also from V36: CloseLibrary(NULL) and CloseDevice on a failed request are safe, RawDoFmt
  returns a useful pointer, and AddTask returns a result.
- **V37 (2.04)** -- CacheClearU, CacheClearE, CachePreDMA, CachePostDMA,
  AttemptSemaphoreShared, StackSwap, RawDoFmt `%u`. ObtainSemaphore stops trashing A0.
- **V39 (3.0)** -- memory pools (CreatePool ... FreePooled), low-memory handlers
  (AddMemHandler/RemMemHandler), ObtainQuickVector, working Procure/Vacate, `MEMF_NO_EXPUNGE`,
  `MEMF_KICK`, the SAD serial debugger, Alert timeout.
- **V40 (3.1)** -- fixes the SAD command numbering. The NDK 3.9 prototypes add no exec
  functions between V39 and V45.
- **V45 (3.9 NDK)** -- NewMinList, the AVL tree functions, RawDoFmt with a NULL PutChProc
  (V45.1). V45 is a RAM-loadable exec, and Kickstart 3.1 ROMs have V40. Check
  `lib_Version >= 45` before calling any of these.
