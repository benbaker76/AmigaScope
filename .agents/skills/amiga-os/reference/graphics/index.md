# graphics.library

graphics.library draws into RastPorts and BitMaps, builds and loads displays (View, ViewPort,
copper lists), manages colours, fonts, sprites, GELs and the display database, and arbitrates
the blitter. It is in ROM on every Amiga; opening it never touches the disk.

- **Base variable:** `GfxBase` (`struct GfxBase *`, graphics/gfxbase.h). In C the name must be
  exactly `GfxBase` because the proto/inline stubs reference it. In assembler use a variable
  such as `_GfxBase`: gfxbase.i's `STRUCTURE GfxBase` already defines the symbol `GfxBase`.
- **Open:** `GfxBase = (struct GfxBase *)OpenLibrary("graphics.library", 39)` (use 37 for
  2.04 compatibility, 40 for WriteChunkyPixels); test for NULL; `CloseLibrary` at exit. Asm:
  gfxbase.i provides the `GRAPHICSNAME` macro for the name string.
- **Calling convention:** `jsr _LVOxxx(a6)` with A6 = GfxBase (include "lvo/graphics_lib.i").
  D0/D1/A0/A1 are scratch, D2-D7/A2-A5 are preserved, results come back in D0. Watch the
  unusual argument registers: A5 for [LockLayerRom](layers-regions-clipping.md#locklayerrom),
  [AttemptLockLayerRom](layers-regions-clipping.md#attemptlocklayerrom) and
  [UnlockLayerRom](layers-regions-clipping.md#unlocklayerrom); A3 for
  [FindColor](colors-and-pens.md#findcolor); A2/A3 for the ExtSprite calls. WaitBlit preserves
  D0/D1/A0/A1, LockLayerRom and AttemptLockLayerRom preserve all registers.
- **Blitter and asynchronous rendering:** most drawing calls may return while the blitter is
  still busy -- see [WaitBlit](blitter-and-timing.md#waitblit).

Version landmarks (from the autodocs and the NDK 3.9 SFD):

- **V33/V34** (1.2/1.3): the original drawing, text, GELs, sprite, region and View API.
- **V36** (2.0): display database and 32-bit ModeIDs (FindDisplayInfo, GetDisplayInfoData,
  GetVPModeID, ModeNotAvailable), MonitorSpecs, GfxNew/GfxAssociate extended nodes, VideoControl,
  TextExtent/TextFit/FontExtent, ExtendFont/StripFont, EraseRect, BitMapScale,
  Read/WritePixelLine8/Array8, BltClear fill value.
- **V37** (2.04): no new calls (the SFD has no V37 section).
- **V39** (3.0, AGA): AllocBitMap/FreeBitMap/GetBitMapAttr, SetRGB32/LoadRGB32/GetRGB32 and
  palette sharing (ObtainPen, ObtainBestPenA, ReleasePen, FindColor, AttachPalExtra),
  GetAPen/SetABPenDrMd/SetWriteMask/SetMaxPen/SetRPAttrsA accessors, double buffering
  (ChangeVPBitMap, AllocDBufInfo), ExtSprites (AllocSpriteDataA, GetExtSpriteA,
  ChangeExtSpriteA), BestModeIDA, CoerceMode, CalcIVG, SetChipRev, ScrollRasterBF; MakeVPort and
  MrgCop return error codes.
- **V40** (3.1): WriteChunkyPixels, `GfxBase->ChunkyToPlanarPtr`, `VC_...` VideoControl tags.
- **V44/V45** (3.5/3.9): the NDK 3.9 SFD adds no graphics.library functions after V40.
